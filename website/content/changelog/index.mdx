# Changelog

All notable changes to Cyclemetry are documented here, organized by version. Cyclemetry follows [semantic versioning](https://semver.org/).

## Releases

| Version | Date | Highlights |
|---------|------|------------|
| [v0.4.0](/changelog/v0-4-0) | 11 October 2026 | Enduro HUD template with unit-tracking labels and compact units, Prompt for rider weight wherever W/kg would render as 0, Feature the newest showcase videos first |
| [v0.3.0](/changelog/v0-3-0) | 7 July 2026 | Export format dialog, time-of-day & lean angle metrics, revamped properties panel |
| [v0.2.0](/changelog/v0-2-0) | 3 June 2026 | Reference video preview, timeline alignment, template browsing |
| [v0.1.3](/changelog/v0-1-3) | 20 May 2026 | Windows & Linux support, new element types, custom fonts |
| [v0.1.2](/changelog/v0-1-2) | 17 May 2026 | GPX waypoint support, Windows FFmpeg bundling |
