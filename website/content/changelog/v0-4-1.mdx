## What's New

### In-App Updates on Windows and Linux

Windows and Linux now update the same way macOS does. Cyclemetry checks for a new version when it starts and shows a banner when one is available. You can also check any time from **Help → Check for Updates**.

- **Windows:** the installer downloads and runs on its own.
- **Linux AppImage:** the AppImage replaces itself in place.
- **Linux `.deb`:** asks for your password, then installs the new package.

If an update check or install fails, the banner now has a **Download** link to the release page.

## Upgrading

- **macOS:** choose **Cyclemetry → Check for Updates**, or accept the update banner.
- **Windows and Linux:** download this version from [GitHub Releases](https://github.com/walkersutton/cyclemetry/releases/tag/v0.4.1). It's the last manual download; later versions arrive in-app.
