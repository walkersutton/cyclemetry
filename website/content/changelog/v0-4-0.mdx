# v0.4.0

  Download from [GitHub Releases](https://github.com/walkersutton/cyclemetry/releases/tag/v0.4.0)

## What's New

### Enduro HUD Template

A new bundled overlay. Its unit captions ("mph", "km/h") follow your unit setting instead of being fixed text. A new **compact units** setting renders "km/h" as "kmh" in value suffixes, chart labels and unit captions.

### Band-Colored Plots

Plots can now color segments by a second metric. Shade an elevation profile from green to red by gradient (blue for descents) for a TdF-style climb profile, or color it by power or heart rate. Course maps color the route line too. The **Color by Metric** section includes a band editor with starter bands for each metric.

### Distance-Based Charts

Elevation and other charts can plot against distance instead of time, so climbs are drawn to scale instead of being stretched out by the slow sections. Turn it on in the chart's Advanced panel.

### New Metrics

- **W/kg** (power-to-weight). If a template uses W/kg and no rider weight is set, Cyclemetry prompts for it in the export dialog, on the preview and in element properties instead of quietly showing 0.
- **Custom metrics.** Extra numeric fields your device records (g-force, core temperature, Connect IQ developer fields and so on) now appear alongside the built-in metrics in the value, plot, meter and color-by pickers.
- **Running totals** for distance and elevation gain/loss.

### Vertical Ride-Summary Template

A new portrait template for ride-summary flyovers.

## Editor Improvements

- Uses the speed your device recorded when the file includes it (FIT, GPX, TCX), and smooths GPS-derived speed to remove jitter
- Snapping when dragging elements on the canvas, and better unit handling
- Better custom font support
- Much faster editing on large rides: the activity file is parsed once and cached instead of being re-parsed on every change
- Plain background behind the preview canvas

## Bug Fixes

- Renders no longer slow to a crawl when Cyclemetry is in the background on macOS (App Nap)
- The window can be dragged while a dialog is open
- Distance-based charts now handle flat rides, indoor rides and metric switches
- Fixed the aspect ratio of the vertical ride-summary template

<Callout type="warning">
  The Enduro HUD template in the template gallery needs v0.4.0. Older versions show `Template parse error: missing field 'text'` when you select it.
</Callout>
